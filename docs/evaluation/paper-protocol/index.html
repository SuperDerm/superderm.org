How the Preprint's Evaluation Differs

The SuperDerm preprint reports results under its own scoring protocol. Challenges on this platform use the community scoring protocol. Both score free-text diagnoses, but they match answers to the documented diagnosis differently. A challenge score is therefore not directly comparable with a number in the preprint.

What Is the Same#

  • Both score free-text differentials: a ranked list of diagnoses for each case.
  • Both use the same metric definitions: top-k accuracy over all cases, and macro top-k recall averaged over diagnoses. A missing answer scores zero.
  • Both use the preprint's taxonomy of 214 diagnoses and its rare and high-consequence designations, made by majority vote of five physicians.

How Answers Are Matched#

Preprint protocol Community protocol
Names and synonyms An exact name, or a synonym from the preprint's dictionary, which maps 21,026 source names to the 214 diagnoses, scores 1 Canonical names plus 63 platform synonyms, marked draft until clinically approved
NOS reference When a case is labelled NOS ("not otherwise specified"), a more specific diagnosis in the same subgroup is also accepted No subtype credit: naming a more specific diagnosis than an NOS reference scores 0
An answer naming another diagnosis Scores 0 Scores 0
Unresolved answers A large language model acting as judge (Qwen3.8-27B, given the subgroup and category) classifies the answer as equivalent, subtype, parent, sibling or different. Equivalents and subtypes are accepted No judge. Matching is deterministic after normalization, and unmapped or ambiguous answers score 0
Multiple choice Each case is also asked as a paired four-option question (MCQ) with the same inputs Open-ended only. Challenges have no multiple-choice question

The preprint's protocol is described in its Section 3.2, "Scoring Free-Text Answers".

Further Community Rules#

  • Strict files. Two names for the same diagnosis in one list, more than three answers, or unknown, repeated or missing case IDs reject the whole file instead of being scored.
  • Explicit abstention. An empty list is allowed. It counts as a miss and stays in the denominator.
  • Cohorts are challenge labels, assigned to each case in the reference file, for example common_mimic.
  • Macro recall covers only diagnoses present in the challenge's reference set. Results report n_diagnoses and n_diagnoses_in_set so the difference is visible.
  • Point estimates only. There are no confidence intervals, and leaderboard ties are exact ties of the published values.
  • Reproducible offline. Anyone can recompute a score from the published scorer, the vocabulary and the same files. Every result records the scorer and vocabulary versions and content hashes.

Why They Differ#

A challenge score must be reproducible by anyone, offline and byte for byte, without a language model or the preprint's full dictionary. The community protocol therefore uses fixed, published matching rules. Because its synonym list is a versioned draft, every result names the vocabulary version it used.

Reporting Results#

  • Label preprint results as author-reported, and name the model, the data split and the protocol behind each number. The official model pages do this.
  • Report a community score with its scorer version, challenge version and vocabulary version. When online evaluation opens (Planned), each published score will link to its evaluation run.
  • Never rank preprint numbers and community scores together.

Training Exposure#

The preprint's photographs without diagnostic labels were used to train the SuperDerm visual encoder. Adding labels to them later does not make them suitable for a new blinded test. New blind evaluations favour cases with documented provenance and no prior use in training, retrieval indexes, development sets, demonstrations or annotation tasks.

The full scorer rules are in evaluator/README.md in the SuperDerm-Release repository. See also the SuperDerm community scorer page and the community scoring protocol.
