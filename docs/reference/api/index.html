API Overview

SuperDerm's pages use a JSON API, and you can call it too. This page lists every endpoint that exists today.

Base Path#

Pages are served under /superderm and the API under /superderm/api/v1. The paths below start at /api/v1; on the public site, add the /superderm prefix. Request and response bodies are JSON, and responses are marked Cache-Control: no-store.

Authentication#

  • Sign in with an email link: POST /api/v1/auth/signin, then POST /api/v1/auth/verify with the token from the link. This sets the session cookie sd_session.
  • The cookie is HTTP-only, SameSite=Lax, secure on HTTPS, limited to the base path, and valid for 30 days. There are no API keys.
  • Public reads need no session. Other endpoints return 401 without one, and check your role, project and the object's permitted uses on every request.

Same-Origin Writes#

Every POST, PUT and PATCH must carry an Origin header matching the site. Requests from other sites, or without the header, get 403 ("Requests that change data must come from the SuperDerm site."). In practice, writes come from SuperDerm pages, including the browser console on a SuperDerm page.

Idempotency-Key#

Endpoints marked † accept an Idempotency-Key header of up to 200 characters.

  • The same user, endpoint, key and request body return the original status and response; the work is not repeated.
  • The same key with a different body returns 409 IDEMPOTENCY_KEY_REUSED.
  • Without the header, the request runs normally.

Drafts use version numbers instead: a stale version returns 409 DRAFT_VERSION_CONFLICT with the saved copy.

Errors#

Errors use one envelope:

{"error":{"code":"INVALID_ANNOTATION","message":"Finding 1: choose at least one term or describe it under “Term not listed”.","field":"regions.0.termIds","retryable":false,"details":[{"path":"regions.0.termIds","message":"Finding 1: choose at least one term or describe it under “Term not listed”."}]}}

code is stable and message is for people. field (the input at fault), row (a manifest row) and details appear only when they apply. retryable says whether the same request may succeed later.

Status Meaning Example codes
401 Not signed in UNAUTHENTICATED
403 Not permitted, or not sent from the site FORBIDDEN, NOT_ELIGIBLE
404 Unknown, or private and not visible to you NOT_FOUND
409 State or version conflict DRAFT_VERSION_CONFLICT, LEASE_EXPIRED, ALREADY_SUBMITTED, IDEMPOTENCY_KEY_REUSED
410 Gone LINK_EXPIRED, WITHDRAWN
413 Over a size limit FILE_TOO_LARGE
422 Invalid input INVALID_INPUT, INVALID_ANNOTATION, INVALID_SUBMISSION, FEEDBACK_REQUIRED
429 Rate limited: 5 sign-in links per address in 15 minutes, or 100 uploads in 10 minutes (2,000 for an import) RATE_LIMITED
500 Unexpected error; retryable INTERNAL

Endpoints#

Account#

Method Path Purpose
POST /auth/signin Email a single-use sign-in link
POST /auth/verify Exchange the link's token for a session
POST /auth/signout End the session
POST /auth/dev-login Development only; disabled in production
GET /me Your display name, credit, roles and accepted rules version
PATCH /me Update your profile and credit preference
POST /me/accept-rules Record the rules and terms versions you accept
GET /notifications Your 50 latest notifications
POST /notifications/{id}/read Mark one notification, or all, as read

Public Data#

Method Path Purpose
GET /public/summary Live public counts with their definitions
GET /datasets Dataset and vocabulary entries, and external sources
GET /models Model and tool entries
GET /challenges Challenges with their stage and question
GET /examples Teaching cases, without answers
GET /examples/{id} One teaching case, without answers
GET /examples/{id}/reveal The documented diagnosis, baseline output and expert annotations
GET /vocabularies/{id} Download a vocabulary as JSON
GET /releases Published releases with checksums and counts
GET /releases/{id}/package Download a release package
POST /releases/{id}/download The package link, SHA-256 and size

Annotation and Review#

Method Path Purpose
POST /projects/{slug}/join Join an annotation project
POST /practice/{batch} Grade a practice answer
GET /annotations/tasks Queues with your eligibility, counts and drafts
POST /annotations/tasks/claim † Claim a task; an empty queue returns {"assignment":null,"reason":"QUEUE_EMPTY"}
GET /annotations/assignments/{id} Your assignment, draft and photo links
PUT /annotations/assignments/{id}/draft Save a draft with its version
POST /annotations/assignments/{id}/renew Extend an active claim
POST /annotations/assignments/{id}/submit † Submit for review
POST /annotations/assignments/{id}/skip Release the claim
POST /assets/{id}/view-ticket A 5-minute ticket for one photo and purpose
GET /reviews Your review queue
POST /reviews/{id}/decision † Decide on an annotation revision

Contributions#

Method Path Purpose
POST /submissions † Create a case, dataset, model or question draft
GET /submissions/{id} Read your submission
PATCH /submissions/{id} Update a draft with its version
POST /submissions/{id}/submit † Lock the revision and get the receipt
POST /uploads Reserve a private upload slot
PUT /uploads/{id}/content Send the file
POST /uploads/{id}/complete Check the size and checksum
POST /issues Report an issue

Staff#

Method Path Purpose
POST /admin/imports Start an import from a registered source
POST /admin/imports/{id}/validate Validate a manifest
POST /admin/imports/{id}/ingest † Import accepted rows
POST /admin/privacy/{id} Clear or reject a derived photo
POST /admin/roles Grant a role
POST /admin/roles/{id}/revoke Revoke a role
POST /annotation-batches Configure a batch
POST /annotation-batches/{id}/{action} Open, pause or close a batch
POST /releases Create a draft release
POST /releases/{id}/freeze † Freeze a draft and queue its build
POST /releases/{id}/publish Publish a built release

Photos are served outside the API, by the media gateway at /superderm/media/{ticket}. See Data and privacy.

Planned#

Not yet available: challenge enrollment, input packages and prediction attempts; access requests; credential verification requests; withdrawal requests and release withdrawal; a combined workspace endpoint; background job status; and cursor pagination of lists.
