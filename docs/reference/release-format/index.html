Release Package Format

SuperDerm community annotations are published as versioned, immutable packages. A package contains only annotations approved by an independent clinical reviewer, on photographs cleared for redistribution. The schema version is superderm-release-1.

Download#

  1. Open SuperDerm community annotations and find the version under Versions.
  2. Note its SHA-256, then select Download for that version.

The file is named superderm-community-annotations-<version>.zip. Anyone can download a published public version, without an account. Superseded versions stay downloadable so that results can be reproduced. Versions use semantic numbers such as 0.1.0, and a number is never reused.

From the API, GET /api/v1/releases lists published versions with their release ID, SHA-256, size and counts, and GET /api/v1/releases/{release_id}/package returns the zip with an X-Content-SHA256 header.

Verify#

Check the zip against the SHA-256 shown on the dataset page:

shasum -a 256 superderm-community-annotations-0.1.0.zip

Then unzip it and check every file from inside its folder:

cd superderm-community-annotations-0.1.0
shasum -a 256 -c SHA256SUMS

Every line should end in OK. On Linux, sha256sum -c SHA256SUMS does the same.

Files#

The zip holds one folder, superderm-community-annotations-<version>/:

File Contents
README.md Version, counts, verification command, intended use, release notes
DATASET_CARD.md Counts, intended use, inclusion rule, known limitations, sources and licences, contributor credit
CITATION.cff Citation metadata
SCHEMA.md Field definitions and the coordinate convention
cases.jsonl One row per case: case_id, body_site, split, image_ids
images.jsonl One row per photograph: image_id, case_id, file, width, height, sha256, source, license, synthetic
annotations.jsonl One row per region, image-quality rating or "Unable to assess" result
splits.json Each case_id mapped to its split
sources.json One entry per source: source, name, rights_holder, license, citation, synthetic
vocabularies/morphology.json, vocabularies/image-quality.json The versioned term lists that term_ids refer to
images/<image_id>.jpg The derived photographs: upright, with metadata removed
SHA256SUMS The SHA-256 of every other file

Images are stored as derived JPEGs, and width, height and sha256 describe those files. A package built from synthetic material says so in README.md and DATASET_CARD.md, and marks its images and sources "synthetic": true.

Annotation Rows#

Every row of annotations.jsonl has:

Field Meaning
annotation_id <result_id>-<n>
result_id The reviewed result the row belongs to
image_id, case_id The photograph and case. image_id is null on an "Unable to assess" row
task_type visible_findings or image_quality
guideline_version The annotation guide version
vocabulary {"id", "version"} of the term list, or null
evidence_type photograph
review_status approved or approved_with_edits
reviewed_at When the result was approved
annotation_revision The submitted revision that was reviewed
credit The annotator's public credit

Visible-findings rows add coordinate_space (oriented_normalized), geometry, cannot_localize, term_ids and certainty. Image-quality rows add assessability and flags. An "Unable to assess" result adds unable_to_assess: true. It never means that no lesion is present.

Example row:

{"annotation_id":"res_5wf9zn5rsr-1","image_id":"ph_pt2a9gajbt","result_id":"res_5wf9zn5rsr","case_id":"c_9agz3qebn7","task_type":"visible_findings","guideline_version":"findings-guide-0.1-draft","vocabulary":{"id":"superderm-morphology","version":"0.1.0-draft"},"evidence_type":"photograph","review_status":"approved","reviewed_at":"2026-11-21T08:47:54.778Z","annotation_revision":"ar_q3qjvm5fe6","credit":"Anonymous contributor","coordinate_space":"oriented_normalized","geometry":{"type":"bbox","values":[0.33,0.28,0.65,0.73]},"cannot_localize":false,"term_ids":["MORPH-024","MORPH-011"],"certainty":"certain"}

Coordinates#

Coordinates refer to the upright image, after the EXIF orientation is applied.

  • The origin is the top-left corner; x increases to the right and y downward.
  • Values are normalized to [0, 1] by the image's width and height, with 6 decimals.
  • A box is {"type": "bbox", "values": [x_min, y_min, x_max, y_max]}.
  • A polygon is {"type": "polygon", "values": [[x, y], ...]}: ordered vertices, implicitly closed.
  • A finding without location has "geometry": null and "cannot_localize": true.

To get pixels, multiply x by width and y by height from images.jsonl.

What Is Left Out#

  • Photographs without redistribution permission. A result is left out if any of its photos lacks it.
  • Results that were returned, recorded as insufficient evidence, superseded or withdrawn, and all work from test projects.
  • Annotators' notes, "Term not listed" descriptions and reviewers' internal notes.
  • Source case and image identifiers, original file names, patient groupings, histories, diagnoses and contact details.

Versions Are Immutable#

A release is frozen first: the exact reviewed results it contains are recorded, and later work goes into the next draft. A worker then rechecks redistribution permission for every photo and builds the package with its checksums. If a photo lost permission after the freeze, the build fails and a new draft is needed. The download appears only after a successful build is published. Rebuilding the same snapshot gives a byte-identical archive. Corrections appear in a new version, and a published version is never edited.

Cite the exact version you used; see How to cite SuperDerm.
