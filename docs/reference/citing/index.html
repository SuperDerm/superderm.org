How to Cite SuperDerm

When you use SuperDerm in a publication, cite the platform, the exact release versions you used, and the original sources of any data.

The Platform#

Until a DOI and repository link are assigned, cite the software as:

SuperDerm contributors. (2026). SuperDerm [Computer software].

This is a placeholder. A DOI or repository link will replace it, so check this page again before you publish.

Releases#

Cite the exact version of every release you used. Versions never change after publication, so the version number identifies the data exactly.

  1. Open the dataset page, for example SuperDerm community annotations, and find your version under Versions.
  2. Use the CITATION.cff file inside the package. It gives the title and version, with "SuperDerm contributors" as authors.
  3. Add the package SHA-256 from the dataset page to your data availability statement.

For example:

SuperDerm contributors. (Year). SuperDerm community annotations (Version x.y.z) [Data set].

Use the year the version was published. If your work depends on the annotation guide or vocabulary, also name the guideline_version and vocabulary version recorded in the rows you used. See Release package format.

Vocabularies and the Scorer#

Catalog entries give their own citation lines:

  • SuperDerm diagnostic taxonomy, version 1.0.0.
  • SuperDerm community scorer, version 1.0.0.

For a challenge result, report the scorer version, the challenge version and the vocabulary version with its content hash. All of them appear in the scorer's output. See Community scoring protocol.

Source Datasets#

A release can include photographs from other sources. sources.json and DATASET_CARD.md in each package list every source with its rights holder, licence and citation. Cite each source you use, and follow its terms.

The Datasets directory also lists external collections with their own citations. SuperDerm links to them for reference and citation only.

The Preprint#

Fang C, Cao X, Talio A, Ye W, Porter CW, Rehg JM, Coffee M. SuperDerm: A Benchmark for Open-Ended Diagnosis of Common and Rare Skin Diseases. Preprint, 2026.

When you quote a result from the preprint, say that it is author-reported and name the model, data split and protocol. See How the preprint's evaluation differs.

Credit to Contributors#

Release packages list contributor credit in DATASET_CARD.md, following each contributor's attribution choice. See Contribution and credit.
