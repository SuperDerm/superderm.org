Share a Model or Tool

Use Share a model or tool to submit a model, adapter, tool or reusable script for clinical photographs of skin disease. Keep the work in your own repository and submit a pinned revision. SuperDerm never runs code that participants upload.

What to Prepare#

What It Is#

Field Required Notes
Type Yes Model, Adapter, Tool or Reusable script
Title Yes
Summary Yes What it does and for whom
Task Yes For example open-ended diagnosis or region detection
Authors or team Yes The people who did the work

Provenance and Licences#

Field Required Notes
Upstream models and versions No Exact revisions, such as a commit hash
Changes you made No What differs from the upstream model
Repository URL Yes A full https:// link
Pinned revision Yes A commit hash or tag
How to obtain weights No Access instructions, if weights are separate
Licences by component Yes Code, weights and vocabularies separately

Reproduce and Evaluate#

Field Required Notes
Reproduction command Yes A command that runs your example end to end
Sample input and expected output No
Evaluation dataset and metrics No Name the dataset version and protocol behind each number
Limitations Yes Known failure modes and scope
Maintainer contact Yes Prefilled with your email address

Preview and Submit#

  1. While you fill in the form, the Preview resource card beside it shows the title, summary, type and task, with the label "author-reported".
  2. Select Preview to check every field. Missing fields are listed at the top, each linked to its field.
  3. Select Submit for Review.

Your receipt shows a submission ID that stays the same through revisions, and the submission appears under Contributions in My workspace. To continue a saved draft later, select Resume Draft there.

Author-Reported or Reproduced#

Label Meaning
Author-reported Review covered the documentation only. The results are the authors' own.
Reproduced A maintainer reran your command on an approved example and recorded the output.

Every new entry starts as author-reported. The results shown on the official SuperDerm model pages come from the preprint, are labelled author-reported, and are not community evaluation runs.

Review and Approval#

Reviewer tools for model submissions are Planned. When review opens, a research maintainer will check the links, dependencies and instructions. Approval creates a separate, citable entry in the Models directory, with its version and a citation link.

Community Adaptations#

An approved entry that adapts an official resource is listed under Community Adaptations on the upstream resource's page, and the two pages link to each other. Today each official model page shows "No community adaptation has been reviewed yet."

To publish a new version, submit the new pinned revision from your repository.

Comparing Results#

To compare models on a challenge, use the community scoring protocol, which you can run locally. Name the dataset version, scorer version and protocol behind every number you report. Online prediction submission is Planned. For how manuscript results were scored, see How the manuscript's evaluation differs.
