SuperDerm Community Scorer

Validates prediction files and computes top-k accuracy and macro top-k recall under the published community scoring rules. Python standard library only, so any score can be reproduced.

Evaluation ToolCode: Available

Availability

Version 1.0.0 is in the public SuperDerm-Release repository under evaluator/.

Inputs
UTF-8 JSONL: one row per case with up to three ranked free-text diagnoses.
Outputs
Validation report with row-level errors, or aggregate metrics with the scorer, vocabulary and data versions.

Limitations

  • This deterministic community protocol differs from the preprint's protocol, which also used an LLM judge for unresolved answers.

Community Adaptations

No community adaptation has been reviewed yet. Submit an adaptation with its repository, pinned revision and a reproducible example.
